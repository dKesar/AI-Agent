# Рубрика оценки

[Сценарий преподавателя](guide.md)

| Критерий | Что проверяем | Баллы |
|---|---|---:|
| Постановка задачи | Пользователь, вход, результат и метрика понятны | 0–4 |
| Архитектура | Обоснован выбор workflow/агента; роли модели и кода разделены | 0–4 |
| Инструмент | Контракт, корректный расчёт, источник, проверка входа | 0–4 |
| Ограничения | Уточнение, запрет чужого идентификатора, условия остановки объяснены | 0–4 |
| Испытания | Исходные случаи, два собственных теста и честные ограничения | 0–4 |

Для каждого критерия: 4 — выполнено и подтверждено; 3 — небольшой недочёт; 2 — частично; 1 — только объяснение без подтверждения; 0 — отсутствует.

Зачёт: **14/20 за работу и 7/10 за индивидуальный тест**. Если решение отключает обязательные проверки для выполнения действия вне заявленных полномочий, верните его на доработку. Обычная ошибка поиска, корректно остановленная проверкой, сама по себе не означает нарушение полномочий.

Не начисляйте дополнительные баллы только за наличие API-ключа или более дорогой модели. Оценивайте объяснение механизма и доказательства. Если использовался резервный сценарий, отдельно зафиксируйте, что код не выполнялся; программные результаты нужно досдать позже.
