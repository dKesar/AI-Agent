# Оценивание начинающего

[Сценарий новой лекции](new-lecture.md) · [Программа](../COURSE.md) · [Форма сдачи](../templates/submission.md)

| Критерий | Что участник показывает лично | Баллы |
|---|---|---:|
| Понимание механизма | Различает sim/llm, выбор и исполнение | 0–2 |
| Собственная настройка | Объясняет своё правило, ключ и номер | 0–2 |
| Проверка | Пять типов с ожиданием до запуска и наблюдаемым фактом | 0–2 |
| Улучшение | Новый вопрос исправлен, прежний повторён, отрицательный пример разобран | 0–2 |
| Объяснение границ | Два ограничения, включая отсутствие настоящей модели | 0–2 |
| Перенос | Новый вопрос обработан и объяснён без диктовки | 0–2 |

2 — самостоятельно с объяснением, 1 — с подсказкой, 0 — не выполнено. Количество подсказок фиксируется для обратной связи. Максимум — 12 баллов.

Ориентир зачёта: **9/12**, все пять типов опытов и собственный экспорт. Обязательна личная демонстрация. Это принятый для курса порог, не научно установленная норма. Индивидуальный тест из прежних материалов можно использовать дополнительно для обратной связи; он не является обязательным условием нового маршрута.

Не начисляйте баллы за дорогую модель, наличие ключа или знание Python. Для маршрута разработчика дополнительно приложите функцию и автотесты, не меняя основных критериев понимания.

В бумажном резерве отмечайте «ручная симуляция». Чтобы утверждать, что человек умеет запускать программу, необходима последующая компьютерная демонстрация.
