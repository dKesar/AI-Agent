Матрица CI: Python 3.11/3.12/3.13. Актуальный удалённый результат смотрите во вкладке Actions. Локальная проверка одной версии сама по себе не подтверждает остальные версии и операционные системы.

Лаунчеры Windows/macOS добавлены для удобства. В этой Linux-среде их двойной щелчок на реальных Windows/macOS не проверялся. До занятия преподаватель проверяет первый запуск именно на компьютерах группы.

Тесты проверяют поведение программы, протокол API на подставных ответах, CLI и путь сохранения собственного правила. Они **не доказывают педагогическую эффективность**. Для этого предусмотрен пилот и проверка отсроченного воспроизведения, см. [рецензию](review/REVIEW.md).
