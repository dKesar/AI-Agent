# Начать здесь: первый результат без знания Python

[Главная страница](README.md) · [Словарь](learner/glossary.md)

Нужны навыки открыть папку, напечатать фразу и выбрать пункт меню. На первом шаге получим один ответ и поймём, откуда он взялся. Исходный код читать необязательно.

## До занятия: подготовка с преподавателем

1. На GitHub выберите **Code → Download ZIP**. Распакуйте архив в обычную папку. Git и аккаунт GitHub для занятия не нужны.
2. Внутри должны быть README.md, START-Windows.cmd и папка agent_lab. Не запускайте файлы внутри ZIP.
3. Преподаватель проверяет Python 3.11+; при необходимости устанавливает с [python.org](https://www.python.org/downloads/). Это подготовка **до начала урока**.

Python — программа, запускающая наш тренажёр. Чтобы пользоваться готовой программой, не нужно сначала изучать язык Python.

## Windows

Откройте `START-Windows.cmd` двойным щелчком. В текстовом окне появится меню «ПРАКТИКУМ: ПОНЯТЬ И СДЕЛАТЬ». Введите `1`, Enter, затем прочитайте приглашение и нажмите Enter ещё раз.

Если ярлык не работает: откройте папку проекта, нажмите адресную строку Проводника, напечатайте `cmd` и Enter. В появившемся окне вставьте:

```bat
py -3 -m scripts.beginner
```

## macOS и Linux

Откройте «Терминал». Напечатайте `cd` и пробел, перетащите распакованную папку проекта в окно терминала и нажмите Enter. Теперь команда будет выполняться из правильной папки. Вставьте:

```bash
python3 -m scripts.beginner
```

На macOS приложен также `START-macOS.command`. Если система не открывает его, используйте команду выше или обратитесь к преподавателю. Защитные настройки системы менять не требуется.

## Что должно получиться

Выберите **1 — Готовый пример**. Предскажите, какое правило поможет установить редактор. Ожидаемый вывод по смыслу:

```text
Черновик готов: сотруднику нужно его проверить.
Шаг 1: Поиск правила в учебной памятке.
  Найдены правила: IT-01
Шаг 2: Получение срока первого ответа.
  Первый ответ: в течение 24 календарных часов.
Шаг 3: Подготовка черновика по найденным данным.
```

Работает симулятор. Он не обращался к нейросети и не отправлял сообщение. Откройте [разбор](learner/worked_example.md), затем [практику 1](practice/01_trace.md).

## Если получилось иначе

| Симптом | Что сделать |
|---|---|
| Команда Python не найдена | Преподавателю проверить установку; Windows: попробовать python, macOS/Linux: python3 |
| No module named scripts или agent_lab | Вернуться в папку, где находится README |
| Окно закрылось | Запустить из терминала описанной командой, чтобы прочитать ошибку |
| needs_input | Программа просит уточнение: это предусмотренный результат |
| Непонятное слово | Открыть словарь; мастер переводит основные результаты |

Для выхода введите `0`; для остановки Ctrl+C. Работа сохраняется в `outputs`. Не удаляйте эту папку перед сдачей.
