# Проверка программного комплекса — 2 ноября 2026 года

Проверена версия после c652eed: входы в курс, просмотр лекции, четыре практических блока, локальное сохранение, JSON-перенос, HTML-отчёты, упаковка, Python-ядро и дополнительный маршрут. Это проверка кода и воспроизводимых сценариев; педагогическая эффективность и визуальная совместимость не объявляются доказанными.

## Исправления

- **Восстановление собственных файлов.** Прежний предел импорта 1 МБ был меньше допустимого объёма экспортируемой работы. Предел согласован с моделью данных и увеличен до 16 МиБ. Проверен реальный перенос допустимой работы больше 1 МБ.
- **Сохранение нескольких блоков.** Вместо четырёх отдельных перезаписей используется один снимок курса. Неудачная запись сохраняет прежний полный снимок; новая работа остаётся доступна в памяти с предупреждением.
- **Повреждённое автосохранение.** Нечитаемая копия не перезаписывается новыми пустыми ответами. Замена разрешается после явного восстановления валидного файла.
- **Одновременный импорт файлов.** Результат более раннего чтения не заменяет работу из последнего выбранного файла. Ошибочный или слишком большой импорт не меняет текущие ответы.
- **Продолжение работы.** В снимке и файле переноса сохраняются последний блок и шаг. Прямое открытие ещё не посещённого блока также корректно запоминает его положение.
- **Переход со старых сохранений.** Старые форматы по-прежнему читаются. Прежние локальные записи удаляются только после успешной записи нового полного снимка. Порядок сериализации сокращён до одного прохода при автосохранении.
- **Две разные главные страницы.** Корневой index.html и site/index.html теперь показывают один текущий курс. Прежняя общая мастерская перенесена в явно помеченный legacy.html. Старые закладки открывают текущие разделы.
- **Согласование лекции.** Экраны 35–41 сайта объясняют текущие четыре блока, самостоятельную проверку и сдачу. Авторский PowerPoint сохранён без изменения и явно обозначен как исходный материал с прежней завершающей главой.
- **Печать отчёта.** Перед печатью раскрываются журналы; после неё восстанавливается прежнее раскрытие. Пользовательский текст по-прежнему экранируется. Оформление отчёта задаёт явные фон и цвет текста.
- **Нижняя панель.** Запас места рассчитывается по фактической высоте панели, включая длинные сообщения; это устраняет известную причину перекрытия последних полей.
- **Переключение лекции.** Ограничение history.replaceState в файловом режиме не останавливает кнопки слайдов. Добавлены проверки крайних номеров, клавиатуры, селектора, ошибок изображений и недоступного полного экрана.
- **Предел попыток и неполный комплект.** При 30 записанных попытках можно вернуться к последнему сохранённому результату и продолжить. При отсутствии обязательного файла стартовая кнопка показывает причину и не притворяется рабочей.
- **Кодировки Windows.** Передача данных в Node для сверки использует явный UTF-8. Python CLI и мастер выводят UTF-8, включая перенаправленный вывод; читаются JSON-файлы UTF-8 с BOM. Проверены эмодзи и принудительно заданная cp1251.
- **Упаковка.** Назначение внутри исходников или над ними отклоняется до записи. Самостоятельный комплект содержит лекцию и все нужные локальные ссылки.
- **Параллельный запуск Python-мастера.** Папка работы резервируется до записи файлов. Два одновременных запуска не выбирают одно назначение.
- **Автоматическая проверка.** Общий запуск JavaScript-тестов не зависит от раскрытия шаблонов командной оболочкой. В CI добавлены Windows и Ubuntu; сохранена матрица Python 3.11–3.13.

## Локальное подтверждение

- 107 JavaScript-тестов: модели, реальные обработчики интерфейса в изолированном DOM-стенде, восстановление, первая попытка итоговой проверки, просмотр лекции и подготовка печати.
- 59 Python-тестов: ядро, ограничения инструментов, CLI, мастер, повтор браузерных пакетов, упаковка и подставной API-транспорт.
- 45 сценариев совпадения старого браузерного движка и Python по статусам, источникам, текстам и журналам.
- Девять учебных случаев Python и шесть проверок эталонного дополнительного задания.
- Проверка локальных Markdown/HTML-ссылок, целостности ZIP, наличия 41 исходного изображения и совпадения упакованных файлов с текущими исходниками.

Проверки выполняются в Windows с Python 3.14.1; отдельный запуск тестов проверяет работу без включённого UTF-8-режима Python. Результат удалённой матрицы CI нужно смотреть по соответствующему коммиту.

## Что ещё требует непосредственной проверки

- Управление браузером выключено в настройках приложения. В этом прогоне не выполнены визуальный осмотр, настоящие касания, режим file:// и фактическая печать в PDF в Edge/Chrome. DOM-стенд не заменяет эти проверки.
- Настоящая модель и сеть не вызывались. Необязательный API-адаптер проверен на подставных ответах; для демонстрации преподавателю нужен собственный реальный запуск или подлинная запись.
- Фактическая длительность, самостоятельность прохождения и сохранение навыка через неделю не измерялись. Оценочная шкала является рабочей рубрикой для пилота.
