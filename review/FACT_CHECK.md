# Проверка фактов и соответствия программе

Для новых презентации и конспекта от 27 октября действует отдельный [лист уточнений](NEW_MATERIALS_AUDIT.md). Он учитывает 41 слайд, точные контракты вызовов и воспроизведённое расхождение примера поиска. Таблица ниже относится к базовому стенду и предыдущей редакции материалов.

Дата: 22 октября 2026 года. Проверены формулировки лекций, практик, методички, инструкции API и соответствие основным веткам исполнения. Это проверка текущей редакции, не гарантия истинности будущих правил пользователя.

| Утверждение | Уточнение / решение | Основание |
|---|---|---|
| Агент всегда означает LLM | Термин шире; курс явно выбирает определение LLM-агента с управлением действиями моделью | [Anthropic](https://www.anthropic.com/research/building-effective-agents) |
| Чат, workflow и агент — взаимоисключающие продукты | Чат — интерфейс; процесс может включать LLM; агент тоже может иметь чат | Разграничение интерфейса и управления, объяснение в лекции 1 |
| Симулятор показывает способности LLM | Нет. Отдельно помечены демонстрация механизма и испытание модели | Simulator.choose и OpenAIModel.choose |
| Участник обучает свою нейросеть | Исправлено: он изменяет памятку готового помощника | scripts/beginner.py; модель и её параметры не обучаются |
| Модель сама выполняет функции | Исправное объяснение: она запрашивает функцию, приложение исполняет и возвращает результат | [OpenAI Function calling](https://developers.openai.com/api/docs/guides/function-calling) |
| strict гарантирует правильный ответ | Схема контролирует форму аргументов; смысл и полномочия проверяет приложение | Документация strict и Toolkit.execute |
| Найденный источник доказывает истинность | Уточнено: источник позволяет проверить основание; применимость и содержание требуют проверки | Ограничение поиска и данных |
| Наш шаблонный поиск является полноценной RAG-системой | Нет; поиск и генерация — разные этапы. У нас упрощённый retrieval и шаблонный итоговый текст | [OpenAI Retrieval](https://developers.openai.com/api/docs/guides/retrieval); курс не заявляет полноценную RAG-систему |
| SLA равен сроку решения | Исправлено/подчёркнуто: в курсе задан только срок первого ответа; числа вымышленные | data/sla.json и текст prepare_draft |
| Черновик означает выполненную отправку | Нет; отправляющего инструмента нет | Toolkit.specs и sent=False |
| Промпт самостоятельно обеспечивает права | Нет; требуются независимые проверки на исполнении | [OWASP](https://cheatsheetseries.owasp.org/cheatsheets/AI_Agent_Security_Cheat_Sheet.html) |
| Injection-тест симулятора доказывает защиту LLM | Нет; границы доказанного явно указаны | test_injection_is_visible_but_not_a_command, test_forbidden_action |
| Время жёстко прерывает любую функцию | Нет; дедлайн кооперативный, сетевой timeout не абсолютное время процесса | run и http_transport |
| store=false означает отсутствие любого серверного хранения | Такое обещание не даётся; действуют условия API | [OpenAI Your data](https://developers.openai.com/api/docs/guides/your-data) |
| Python 3.10 подходит для новой установки | Минимум курса повышен до 3.11, т.к. 3.10 завершил поддержку; рекомендуются поддерживаемые версии | [Python releases](https://www.python.org/downloads/) |
| Хорошо структурированный курс гарантирует усвоение каждому | Нет; это проектное решение, требующее пилота | review/REVIEW.md и инструкция преподавателю |

## На чём основаны методические изменения

[IES/WWC, Organizing Instruction and Study](https://ies.ed.gov/ncee/wwc/PracticeGuide/1): чередование разобранного решения и самостоятельной задачи, возвращение к материалу, вопросы на воспроизведение и объяснение. У рекомендаций разный уровень доказательств; они не подтверждают эффективность именно этого курса для взрослых.

[AERO, Explicit instruction](https://www.edresearch.edu.au/guides-resources/practice-guides/explicit-instruction-practice-guide-full-publication): разбивать навык на шаги, показывать выполнение, постепенно уменьшать помощь, проверять понимание. Перенос в этот курс — методическое решение автора; исследования не являются испытанием нашей программы.

Внешние тексты не скопированы. Список источников не заменяет проверку актуального API и локальные тесты. Режим настоящей LLM в этой редакции без ключа не запускался.
