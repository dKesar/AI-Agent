# Практика 2. Создать своё правило — 45 минут

[Предыдущая](01_trace.md) · [Далее](03_controls.md) · [Версия для знающих Python](developer_tools.md)

**Результат:** ваша собственная памятка, вопрос и файл результата. Программировать не нужно. Вы настраиваете готовый симулятор; модель не обучается.

| Минуты | Действие |
|---|---|
| 0–5 | Посмотреть, что создаём и где это сохранится |
| 5–15 | Вместе повторить разобранный пример командировки |
| 15–30 | Создать свою задачу с уменьшающимися подсказками |
| 30–40 | Проверить влияние ключевого слова и срочности |
| 40–45 | Объяснить партнёру, что изменили |

## Вместе: командировка

Откройте мастер и выберите **4 — Создать своё правило и пример**. Введите:

| Поле | Значение | Зачем |
|---|---|---|
| Название | Командировка | Человеку понятно, о чём правило |
| Номер | TR-01 | Уникальная ссылка на источник |
| Ключевые слова | командиров | Совпадёт с началом «командировка», «командировку» |
| Текст | Для командировки укажите цель, даты и согласование руководителя. | Сведения для ответа |
| Вопрос | Как оформить командировку? | Проверка нового правила |
| Срочно? | 1 | Обычный учебный срок |

Пример полностью вымышленный. Ожидайте TR-01, 24 часа и черновик. Мастер сохранит в `outputs/my_case` файлы `policies.json`, `task.json`, `result.json`. Если папка существует, создаст `my_case_2`, затем следующую: прежняя работа останется.

Файл — просто сохранённая информация. `policies.json` содержит вашу копию памятки, `task.json` — вопрос, `result.json` — наблюдавшийся запуск. Увидеть файлы можно в Проводнике или Finder.

## Самостоятельно: бронирование переговорной

Снова пункт 4. Придумайте понятное правило бронирования. Подсказки только для первых двух полей: название «Переговорная», номер «MEET-01». Самостоятельно выберите ключ и сформулируйте вопрос так, чтобы ключ встретился в начале одного слова. Задайте срочный приоритет `2`.

Ожидаемый смысл: выбран ваш источник, срок первого ответа — 4 часа. Если получилась передача человеку, это повод проверить совпадение вопроса и ключа.

<details><summary>Первая подсказка</summary>

Слова «переговорная» и «переговорную» начинаются одинаково. Можно использовать ключ «переговор».

</details>
<details><summary>Вторая подсказка</summary>

Пример вопроса: «Как забронировать переговорную?» Правило: «Укажите дату, время и число участников». Это учебные данные, а не настоящее бронирование.

</details>

## Связь причины и результата

В новой записи меняется содержание памятки, но программа поиска остаётся прежней. Если добавить только новое название без подходящего ключа, вопрос не начнёт распознаваться автоматически. Знание появилось в данных; «интеллект» модели мы не тренировали.

**Готово, если:** есть хотя бы один самостоятельно настроенный пример с вашим источником; вы показываете три файла и объясняете назначение каждого. При следующей практике используйте папку своего примера.
