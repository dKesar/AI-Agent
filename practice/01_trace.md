# Практика 1. Запустить и объяснить — 45 минут

[Маршрут](../README.md) · [Следующая практика](02_tools.md)

**Цель:** найти в коде выбор действия, исполнение инструмента, состояние и условие завершения. До начала нужно уметь запускать Python и читать словарь. Работайте в паре: оператор и наблюдатель; через 20 минут поменяйтесь.

| Минуты | Действие |
|---|---|
| 0–5 | Проверка окружения |
| 5–15 | Предсказание и запуск обычного обращения |
| 15–25 | Сравнение с доступом и неоднозначностью |
| 25–35 | Поиск соответствующих функций в коде |
| 35–45 | Заполнение отчёта, объяснение партнёру |

```bash
python -m scripts.check_environment
python -m agent_lab --case normal
python -m agent_lab --case access
python -m agent_lab --case ambiguous
python -m examples.workflow
```

До каждой команды запишите ожидаемые источник и статус. После запуска перенесите факты в копию [таблицы испытаний](../templates/test_report.md), которую сохраните в `outputs/`.

В [core.py](../agent_lab/core.py) найдите `Simulator.choose`, `Toolkit.execute`, `_dispatch`, `run`. Ответьте:

1. Кто выбрал `get_sla`? Где фактически получены часы?
2. Почему `normal` и `access` используют разные регламенты?
3. Почему `ambiguous` не заканчивается черновиком?
4. Где проверяется совпадение приоритета с исходной заявкой?
5. Что действительно изменится при `--mode llm`, а что останется тем же?

**Самостоятельная мини-задача:** скопируйте [custom_task.json](../examples/custom_task.json) в `outputs/my_task.json`, измените вопрос на запрос справки и приоритет на `urgent`. Запустите:

```bash
python -m agent_lab --task outputs/my_task.json --json
```

Ожидайте `HR-01`, 4 часа и `awaiting_review`. Не меняйте код, чтобы получить нужный результат: вход уже управляет поиском.

**Критерий готовности:** отчёт содержит три исходных случая и ваш JSON; вы можете показать четыре функции и объяснить один переход по журналу. Скриншот терминала без объяснения не заменяет отчёт.

Если базовый запуск не работает: проверьте версию Python, текущую папку и [подготовку](../instructor/guide.md). Результаты для самопроверки находятся в [разборе](../solutions/README.md).
