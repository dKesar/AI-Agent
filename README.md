# ИИ-агенты: понять и сделать своими руками

**[Открыть курс: лекция и практика](index.html).** Собраны четыре практических блока с планом по 45 минут, итоговый HTML-отчёт и один файл сохранения всей работы. Длительность и понятность требуют пробного занятия. [План на 180 минут](practice/agent-anatomy-plan.md).

Курс для взрослых **без опыта программирования и работы с ИИ**. Текущая программа основана на новой лекции Клименко и Сверкунова: **41 слайд, четыре главы и история Ани**. За шесть академических часов вы разберётесь в механизме и настроите готового учебного помощника. Основная практика выполняется в браузере без Python и API-ключа.

## Что вы получите

1. Объясните разницу между ответом в чате, заданным процессом и LLM-агентом.
2. Запустите пример и объясните три его действия.
3. Сравните отсутствие данных, неоднозначность и ошибку инструмента.
4. Проверите, как разрешения и лимиты влияют на выполнение задачи.
5. Выберете инструменты для другой задачи и сдадите один отчёт с прогнозами, результатами и объяснениями.

Это начальный уровень. Самостоятельная разработка промышленного агента или обучение Python с нуля за одно занятие не обещаются.

## Маршрут

Сначала преподаватель проводит очную лекцию на общем экране: 90 учебных минут. Затем каждый участник самостоятельно проходит [практикум](site/agent-anatomy/index.html):

1. **Устройство помощника** — наблюдать вызовы, различить роли и проверить влияние срочности.
2. **Новые ситуации** — записать прогнозы и сравнить три причины изменения результата.
3. **Ограничения** — проверить запрещённую отправку и бюджет в один или три вызова.
4. **Новая задача** — выбрать инструменты для подбора переговорной, проверить два расписания и объяснить результат.

Каждый блок рассчитан на 45 минут по плану. **90 + 180 = 270 учебных минут**, перерывы отдельно. В конце участник скачивает один HTML-отчёт. Перед сдачей есть самостоятельная проверка нового случая: первая попытка и объяснение сохраняются до показа разбора. [Шкала для преподавателя](instructor/anatomy-rubric.md). Понятность и время ещё нужно проверить на пробной группе. Создание своего правила и дополнительные задания Python сохранены как материалы прежнего маршрута; они не входят в эти четыре блока.

## Симулятор и настоящий ИИ

В основном маршруте работает **симулятор**: действия выбирают готовые условия. Он позволяет без сети изучить механизм, изменить разрешения и лимиты, проверить требования к результату. Свободный текст объяснений читает преподаватель; нейросеть его не оценивает.

В режиме `llm` инструменты выбирает настоящая языковая модель. Преподаватель показывает [реальный API-запуск или запись реального прогона](examples/llm.md). Если доступа нет, он сообщает, что группа испытала только симулятор. Прохождение симулятора не доказывает качество LLM.

## Разработчику

Python **3.11+**, матрица CI — 3.11/3.12/3.13; для новой установки выбирайте актуальную поддерживаемую версию. Сторонних пакетов нет. Команды выполняются из корня:

```bash
python -m scripts.beginner
python -m agent_lab --case normal
python -m agent_lab --task outputs/my_case/task.json --policies outputs/my_case/policies.json
python -m unittest discover -s tests -v
python -m scripts.run_cases
python -m scripts.check_exercise --solution
python -m scripts.check_links
node scripts/test_browser.mjs
python -m scripts.import_browser_work ai-agent-work.json
```

В Windows можно использовать `py -3`, в macOS/Linux — `python3`. `check_exercise` без `--solution` проверяет заготовку дополнительного задания и до её выполнения падает намеренно. Для основного маршрута он не нужен.

SLA в стенде — срок **первого ответа**, а не решения обращения. Все цены и правила вымышлены. Отправки сообщений и покупки нет. Поиск по началу слов может ошибаться; источник помогает проверить ответ, но не гарантирует истинность.
