ПРАКТИКУМ. УСТРОЙСТВО ПОМОЩНИКА

Четыре блока самостоятельной практики после очной лекции.
Плановое время — по 45 минут. Таймера ожидания нет.

1. Распакуйте весь ZIP в обычную папку.
2. Откройте index.html двойным щелчком.
3. Следуйте подсказке и основной кнопке внизу экрана.
4. После первого блока перейдите ко второму по той же кнопке.
5. После второго перейдите к третьему: «Ограничения».
6. После третьего перейдите к четвёртому: «Новая задача».
7. В конце четвёртого скачайте итоговый HTML-отчёт, откройте его
   для проверки и передайте преподавателю.

Интернет, Python, установка программ и ключ модели не нужны.
Это сценарная симуляция: настоящая нейросеть не запускается.

Перед закрытием откройте «Моя работа» и сохраните файл
для продолжения. Он включает все четыре блока; восстановить его можно
через то же меню. Автосохранение зависит от браузера.
Старый файл работы первого блока тоже можно восстановить.

guide.html — памятка преподавателю.
Не открывайте index.html внутри архива: сначала распакуйте папку.
План всей практики — 180 минут. Длительность нужно проверить
на пробном занятии; сайт не требует ждать по таймеру.
