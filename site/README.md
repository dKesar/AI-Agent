# HTML курс и браузерный практикум

Интерфейс и практикум проверены локально. Автономный ZIP передан автору курса. Онлайн-публикация пока не подтверждена: два развёртывания завершились неизвестной внутренней ошибкой хостинга. Проект и версии сохранены; повторной регистрации и изменения доступа не выполнялось.

Основной сценарий — [программа](../COURSE.md). Страница использует обычные HTML, CSS и JavaScript, без библиотек и серверного API. `app.js` — готовый автономный bundle; при изменении исходников пересоберите его:

```bash
node scripts/build_browser_site.mjs
python -m scripts.check_browser_parity
```

Готовая автономная копия со всеми изображениями и оригиналами передана ZIP-архивом. После успешной публикации её также можно будет скачать в разделе сайта «Преподавателю». Распакуйте и откройте index.html. Автосохранение из file:// зависит от браузера, поэтому сохраняйте пакет JSON вручную.

Из этого репозитория локально откройте `site/index.html`. Для просмотра исходных слайдов и скачивания оригиналов дополнительно нужна папка `site/assets`: она входит в развёрнутую версию сайта и автономный ZIP, но бинарные пользовательские материалы не дублируются в этом каталоге GitHub. Снимок текстов и заметок хранится в source-data.mjs; приложение не загружает данные через fetch. Скопируйте assets из автономного комплекта, если нужен полный файловый просмотр.

## Границы реализации

Браузерный engine.mjs повторяет базовый симулятор: поиск по началу слов, SLA, черновик, уточнение, передача сотруднику, лимит шагов и отказ поиска. Ключи ограничены русским и английским алфавитом, цифрами и подчёркиванием. Сравнение с Python исключает время выполнения. Динамический тайм-аут сети, реальная модель, авторизация и дополнительная закупка не исполняются.

Ожидания, результаты и снимки памятки сохраняются локально в браузере. Изменение правила не переписывает старые попытки. Экспорт ai-agent-work/v1 переносится в `scripts.import_browser_work`, где результаты заново вычисляются Python-ядром. История служит учебным отчётом, а не защищённой системой экзамена.

Данные участника выводятся как текст; они не становятся HTML или исполняемым кодом. Настоящих сообщений, покупок или внешних LLM-запросов сайт не совершает. Доступ к опубликованному сайту по умолчанию остаётся частным.
