# HTML курс и браузерный практикум

Текущая практика после очной лекции находится в [agent-anatomy/index.html](agent-anatomy/index.html): четыре блока, итоговый HTML-отчёт и сохранение всех ответов. Её автономный комплект собирается из корня командой `python scripts/package_anatomy.py ../agent-anatomy`. Корневой index.html предлагает отдельные входы в лекцию и практику.

Текущая лекция открывается в [lecture.html](lecture.html): 34 изображения исходника и 7 адаптированных завершающих экранов, переключатель, клавиши стрелок, полный экран при поддержке браузером и скачивание PowerPoint. Прежний маршрут доступен отдельно в [архиве](legacy.html). Корневой index.html и site/index.html открывают текущий курс.

Полный комплект включён в репозиторий. Скачайте репозиторий через **Code → Download ZIP**, распакуйте и откройте корневой `index.html` или `OPEN-COURSE.cmd` в Windows. Можно также скачать [отдельный автономный ZIP](assets/offline-course.zip). Онлайн-публикация пока не подтверждена.

Основной сценарий — [программа](../COURSE.md). Страница использует обычные HTML, CSS и JavaScript, без библиотек и серверного API. `app.js` — готовый автономный bundle; при изменении исходников пересоберите его:

```bash
node scripts/build_browser_site.mjs
python -m scripts.check_browser_parity
```

Готовая автономная копия со всеми изображениями и оригиналами передана ZIP-архивом. После успешной публикации её также можно будет скачать в разделе сайта «Преподавателю». Распакуйте и откройте index.html. Автосохранение из file:// зависит от браузера, поэтому сохраняйте пакет JSON вручную.

Из этого репозитория можно также открыть `site/index.html`. Папка `site/assets` уже содержит 41 изображение слайдов, оригиналы и материалы. Снимок текстов и заметок хранится в source-data.mjs; приложение не загружает данные через fetch.

После изменения материалов пересоберите комплект из корня репозитория:

```bash
node scripts/build_browser_site.mjs
python -m scripts.package_browser_site
```

Оригиналы берутся из `lectures/visual`, учебные тексты — из соответствующих Markdown-файлов. Скрипт проверяет наличие 41 изображения и записывает SHA-256 оригиналов в `site/assets/manifest.json`. В ZIP входят корневой экран выбора, OPEN-COURSE.cmd и папка site с лекцией и четырьмя блоками практики. Архив не включает сам себя; после сборки проверяются целостность и обязательные материалы.

## Границы реализации

Браузерный engine.mjs повторяет базовый симулятор: поиск по началу слов, SLA, черновик, уточнение, передача сотруднику, лимит шагов и отказ поиска. Ключи ограничены русским и английским алфавитом, цифрами и подчёркиванием. Сравнение с Python исключает время выполнения. Динамический тайм-аут сети, реальная модель, авторизация и дополнительная закупка не исполняются.

Ожидания, результаты и снимки памятки сохраняются локально в браузере. Изменение правила не переписывает старые попытки. Экспорт ai-agent-work/v1 переносится в `scripts.import_browser_work`, где результаты заново вычисляются Python-ядром. История служит учебным отчётом, а не защищённой системой экзамена.

Данные участника выводятся как текст; они не становятся HTML или исполняемым кодом. Настоящих сообщений, покупок или внешних LLM-запросов сайт не совершает. Доступ к опубликованному сайту по умолчанию остаётся частным.
