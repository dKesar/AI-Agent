# Архитектура учебного стенда

[README](../README.md)

| Файл | Ответственность |
|---|---|
| [core.py](../agent_lab/core.py) | Контракты, поиск, проверки, состояние, симулятор, цикл |
| [openai_adapter.py](../agent_lab/openai_adapter.py) | Responses API, история, call_id, диагностика |
| [__main__.py](../agent_lab/__main__.py) | Параметры CLI, выбор режима, вывод |
| [data](../data) | Вымышленные регламенты, цены и случаи |
| [tests](../tests) | Поведение ядра, протокол адаптера, CLI |

`Action` — имя и аргументы. `Toolkit` владеет доверенным состоянием. `Simulator` выбирает действия условиями. `OpenAIModel` выбирает действия через API. `run()` не зависит от того, кто выбрал действие: он проверяет время, вызывает инструмент, записывает журнал и передаёт наблюдение обратно.

Схемы инструментов и локальная проверка типов используют одну таблицу `Toolkit.specs`. Проверки смысла расположены в `_dispatch`. `prepare_draft` требует один найденный регламент и полученный SLA; модель не может заменить факт поиска произвольным идентификатором.

## Конечные статусы

| Статус | Значение | Что делать |
|---|---|---|
| `awaiting_review` | Черновик сформирован | Проверить содержание человеком |
| `needs_input` | Не хватает данных или нужен выбор | Создать уточнённую задачу и запустить заново |
| `needs_human` | Нет правила, запрещённый вызов или повторные ошибки | Передать сотруднику |
| `step_limit` | Израсходован бюджет вызовов | Посмотреть журнал, не увеличивать лимит вслепую |
| `time_limit` | Проверка обнаружила истечение времени | Проверить медленный этап |
| `model_error` | Сбой модели/адаптера/протокола | Читать безопасный код ошибки |
| `invalid_input` | Неверная структура или лимиты | Исправить вход |

## Что здесь не реализовано

Это локальный стенд, а не сервер: нет HTTP API, базы, многопользовательской авторизации, отправки писем, фоновых очередей или жёсткой изоляции произвольного Python-кода. Уточнение не возобновляет предыдущую сессию. Журнал фиксирует действия, а не внутренние рассуждения модели. Ограничения подробнее — в [LIMITATIONS](../LIMITATIONS.md).

## Разбор обычного случая

1. `search_policy` получает исходный вопрос, возвращает `IT-01` и записывает `matches`.
2. `get_sla` получает `normal`, проверяет соответствие заявке, возвращает 24 часа.
3. `prepare_draft` принимает только найденный идентификатор и формирует текст.
4. `run` возвращает `awaiting_review`; фактической отправки нет.

Откройте [normal.json](normal.json): это результат запуска симулятора, сохранённый при подготовке. Длительность зависит от машины, поэтому не сравнивайте её побайтно между запусками.
