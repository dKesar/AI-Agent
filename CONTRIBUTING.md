# Работа с учебным репозиторием

[README](README.md)

Начните с практик. Для самостоятельных изменений создайте личную ветку. Не коммитьте ключи, `.env`, реальные заявки и локальные отчёты из `outputs/`.

Перед предложением изменения выполните из корня:

```bash
python -m unittest discover -s tests -v
python -m scripts.run_cases
python -m scripts.check_exercise --solution
python -m scripts.check_links
```

Если изменяли студенческую функцию, дополнительно выполните `python -m scripts.check_exercise`. Если меняли поиск, добавьте случай, который обосновывает изменение, и отрицательный пример. Не удаляйте проверку только потому, что новый код её не проходит.

В описании изменения укажите: проблему, новый результат, команду проверки и ограничения. Если реальную LLM не запускали, так и напишите; подставные HTTP-ответы проверяют протокол, а не модель.

CI использует стандартную библиотеку Python и не требует секретов. В нём проверяются версии 3.10, 3.12 и 3.13. Изменение учебной программы согласуйте с расписанием: объём остаётся 90 минут лекции и 180 минут практики/контроля.
